Simple Python Network Scanner

The Goal

I was curious about how computers find open "doors" (ports) on a network, so I decided to write a very basic Python script to knock on those doors and see who answers.

The Code

I didn't use any complicated external tools—just a simple loop using Python's built-in socket library.

import socket

target = '127.0.0.1' # Checking my own machine

print("Scanning for open ports...")

for port in range(1, 101):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.5) 
    
    if s.connect_ex((target, port)) == 0:
        print(f"Port {port} is OPEN")
        
    s.close()

print("Scan complete.")

How It Works

  • The script picks an IP address and a list of port numbers (1 through 100).
  • It uses connect_ex() to literally try and connect to each port, waiting half a second for a response.
  • If the connection is successful (which returns a 0), the script prints out that the port is open and listening.

What I Learned

This quick experiment showed me how easy it is to interact with a network using just a few lines of code. It gave me a practical, hands-on understanding of how IP addresses and network ports actually work together behind the scenes.
