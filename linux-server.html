Hosting a Local Web Server on Linux

The Goal

I wanted to see exactly how a website works under the hood. Instead of relying on a drag-and-drop website builder, I used the Linux terminal to turn my computer into a fully functional local web server.

The Step-by-Step Process

Step 1: Installing the Web Server
Instead of downloading a graphical installer, I used the Linux package manager. These two commands downloaded Apache and started the web service running silently in the background.

sudo apt update
sudo apt install apache2

Step 2: Finding Where the Website "Lives"
Linux automatically creates a specific directory for hosting web files. I used the terminal to navigate to that folder, removed the default placeholder, and created a new index.html file to hold my own custom text.

cd /var/www/html
sudo nano index.html

Step 3: Going Live on My Network
To actually view the website from another device, I needed to know where to point my browser. I used the network command to find my computer's local IP address.

ip a

I grabbed my phone, connected it to the same home Wi-Fi network, and typed that IP address (e.g., 192.168.1.15) into my browser.

What I Learned

My custom HTML page loaded instantly on my phone. This project completely demystified the internet for me. It showed me firsthand how simple command-line instructions translate into a live, running service, and how IP addresses act as the bridge between different devices on the same network.
