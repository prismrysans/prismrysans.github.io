Hosting a Locally Created Website on a Linux Server

The Goal

To take a custom website I built locally (using HTML and CSS) and deploy it onto a Linux environment. By setting up Apache/Nginx, the goal was to transform a basic folder of code into a live web service accessible across the local network.

The Deployment Process

Step 1: Installing the Web Server Engine
First, I needed software to serve my files to a browser. Using the Linux terminal, I installed Apache2 (or Nginx) which immediately began running as a background service.

sudo apt update
sudo apt install apache2

Step 2: Deploying the Custom Website Files
Linux web servers look for website files in a specific root directory (/var/www/html). I cleared out the server's default placeholder page and used terminal commands to copy my locally built HTML/CSS project folder directly into the server's live directory.

sudo rm /var/www/html/index.html
sudo cp -r ~/my-local-website/* /var/www/html/

Step 3: Configuring Network Access & Testing
With the files in place, the website was live. To view it from another device, I used the networking tool to check the server's assigned local IP address.

ip a

By entering that IP address (e.g., 192.168.1.50) into my smartphone's web browser while on the same Wi-Fi network, my custom-built HTML/CSS website loaded perfectly.

What I Learned

This project was a practical introduction to systems & network administration principles and server deployment. It enabled me to understand the basic web development (writing the code) and server deployment (hosting the code), proving how a standard Linux machine can be configured to host and serve custom web content over a network.
